# Earth textures: sources and regeneration

All maps use longitude −180° to 180°, latitude 90° to −90° (equirectangular). The application converts the source images to WebP and resizes them; they are not current observations.

- `earth01.webp` and `earth_day_blue_marble_*.webp`: NASA Earth Observatory, Blue Marble: Next Generation, July 2004, base map, 21600 × 10800. Imagery by Reto Stöckli, NASA Earth Observatory (NASA GSFC). [Source page](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/), [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- `earth02.webp` and `earth_day_natural_*.webp`: [Natural Earth I, 1:10m, medium, archive version 2.0.0](https://www.naturalearthdata.com/downloads/10m-raster-data/10m-natural-earth-1/) (16200 × 8100), with an ocean color added using the land mask. [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/) place its data in the public domain.
- `earth_night_lights_*.webp`: [NASA Earth Observatory, Black Marble 2012 Color Maps v2](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/), 13500 × 6750. NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA GSFC.
- `earth_ocean_mask_*.webp`: rasterized from Natural Earth 1:10m land polygons v5.1.2. White means ocean and black means land; lakes are treated as water. This is a map-derived approximation, not a bathymetry dataset.
- `earth_surface_normal_*.webp`: a flat normal generated by the script; it does not represent measured terrain. Relief, where visible, is baked into the base image.
- `earth_clouds_*.webp`: deterministic procedural noise generated by the script, used only for visual decoration. It is not real cloud cover.
- `earth_country_borders_4096.webp`: Natural Earth [Admin 0 – Boundary Lines, 1:50m, v5.1.2](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-boundary-lines-2/), a public-domain land boundary mask without coastlines. See `scripts/generate-earth-borders.py` for its source URL and regeneration command.

## Rebuild

Requires Python 3.9+ and Pillow with WebP support. Download the exact files below to a temporary directory; the script verifies SHA-256 hashes before generating any outputs. Keep the downloaded input files out of the repository.

```sh
mkdir -p /tmp/earth-sources
curl -fL 'https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/july/world.200407.3x21600x10800.jpg' -o /tmp/earth-sources/blue.jpg
curl -fL 'https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144875/BlackMarble_2012_3km.jpg' -o /tmp/earth-sources/night.jpg
curl -fL 'https://naturalearth.s3.amazonaws.com/10m_raster/NE1_LR_LC.zip' -o /tmp/earth-sources/natural-earth.zip
curl -fL 'https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_land.geojson' -o /tmp/earth-sources/land.geojson
python3 scripts/generate-earth-textures.py /tmp/earth-sources
```

The 16000-pixel Natural Earth output is resampled down from the 16200 × 8100 source. Cloud images above 2048 pixels are upscaled synthetic noise. Exact compressed bytes can vary by Pillow and WebP version.
