# Earth textures: sources and regeneration

Each image is named `<layer>-<width>.webp` (`4k` = 4096 × 2048, `8k` = 8192 × 4096, `2k` = 2048 × 1024). All maps use longitude −180° to 180°, latitude 90° to −90° (equirectangular). The application converts the source images to WebP and resizes them; they are not current observations.

- `day-blue-marble-*.webp`: NASA Earth Observatory, Blue Marble: Next Generation, July 2004, base map, 21600 × 10800. Imagery by Reto Stöckli, NASA Earth Observatory (NASA GSFC). [Source page](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/), [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- `day-natural-*.webp`: [Natural Earth I, 1:10m, medium, archive version 2.0.0](https://www.naturalearthdata.com/downloads/10m-raster-data/10m-natural-earth-1/) (16200 × 8100), with an ocean color added using the land mask. [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/) place its data in the public domain.
- `night-lights-*.webp`: [NASA Earth Observatory, Black Marble 2012 Color Maps v2](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/), 13500 × 6750. NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA GSFC.
- `ocean-mask-*.webp`: rasterized from Natural Earth 1:10m land polygons v5.1.2. White means ocean and black means land; lakes are treated as water. This is a map-derived approximation, not a bathymetry dataset.
- `clouds-2k.webp`: deterministic procedural noise generated by the script, used only for visual decoration. It is not real cloud cover. It is only shipped at 2k because a larger version would be an upscale of the same noise.
- `country-borders-4k.webp`: Natural Earth [Admin 0 – Boundary Lines, 1:50m, v5.1.2](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-boundary-lines-2/), a public-domain land boundary mask without coastlines. See `scripts/generate-earth-borders.py` for its source URL and regeneration command.

## Rebuild

Requires Python 3.9+ and Pillow with WebP support. Download the exact files below to a temporary directory; the script verifies SHA-256 hashes before generating any outputs. Keep the downloaded input files out of the repository.

```sh
mkdir -p /tmp/earth-sources
curl -fL 'https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/july/world.200407.3x21600x10800.jpg' -o /tmp/earth-sources/blue.jpg
curl -fL 'https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144875/BlackMarble_2012_3km.jpg' -o /tmp/earth-sources/night.jpg
curl -fL 'https://naturalearth.s3.amazonaws.com/10m_raster/NE1_LR_LC.zip' -o /tmp/earth-sources/natural-earth.zip
curl -fL 'https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_land.geojson' -o /tmp/earth-sources/land.geojson
python3 scripts/generate-earth-textures.py /tmp/earth-sources
```

The 4k images load first (`index.html` starts their download before the scripts arrive); once the globe is drawn and the page is idle, the 8k versions download one at a time and replace them on GPUs that support 8192-pixel textures. Images are decoded off the main thread with `createImageBitmap` (see `src/lib/earthTextureLoader.ts`). Clouds and country borders are only downloaded when turned on. Exact compressed bytes can vary by Pillow and WebP version.
