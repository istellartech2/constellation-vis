# UI/UX レビュー：3Dモデルライブラリ（読み込みダイアログ）

> **状態: 対応済み（記録として保管）。** 初版（表示タブ「3Dモデル」・読み込み／編集ダイアログ）に対するレビューの指摘と、その対応。
> 実装: `src/components/ui/ModelImportDialog.tsx`、`ModelPreview.tsx`、`ModelLibrarySection.tsx`、`src/lib/modelLibrary/`。
> 設計は [trajectory-layer.md › Model library](trajectory-layer.md#model-library-srclibmodellibrary)、
> 機体座標への合わせ方は [satellite-attitude.md](satellite-attitude.md#読み込んだ3dモデルを機体座標に合わせる)。

| # | 優先度 | 指摘 | 対応 |
| --- | --- | --- | --- |
| 1 | MUST | 自動推定が CAD の Z-up 書き出しで外れる（mm・Z-up・前方 +Y・センサ −Z・翼が X 方向のモデルで「前方 +Z / 地球側 −Y」） | 軸の選択の上に「元データの上方向: Y-up（glTF標準）/ Z-up（CAD）」を追加し `autoOrientation` に渡す（衛星: 地球側 = −上、水平の長い辺 = 翼、残り = 前方。例のモデルは 前方 +Y / 地球側 −Z）。切り替えると再推定。保存値 `sourceUp`。プレビュー左下にモデル自身の軸（細線・「モデル X/Y/Z」）のギズモ。選択の下に「CAD（Z-up）由来なら地球側は多くの場合 モデル −Z」 |
| 2 | MUST | プレビューの軸ラベルが見切れる | 機体軸のラベルを 3D から外し、プレビュー左上の固定凡例（赤 +X 進行方向／緑 +Y／青 +Z 地球方向（センサ））に。モデル軸は左下のギズモ内に描くので見切れない |
| 3 | SHOULD | モデルが小さい（枠の 1/3） | 最大辺の約 1.3 倍の距離で表示。機体軸の矢印は細く半透明（不透明度 0.6、長さ 0.45×最大辺） |
| 4 | SHOULD | パドル選択が見えない | 選んだノードを黄色の枠で表示。「回転を確認」スライダー（0–180°）で機体 Y 軸まわりに回して確認。メッシュ数は「メッシュ 5」と表記。入れ子の選択は数に含めない |
| 5 | SHOULD | 機能が見つけにくい | 近接中の衛星カードに「機体モデル: 標準バス · 変更…」。表示タブ › 3Dモデルを開いて展開（`OpenTabRequest.model = "reveal"`、アンカー `display-models`）、ライブラリが空なら読み込みダイアログ（`"import"`）。3Dモデルの開閉は制御状態にし、ライブラリの読み込み完了後も 1 回目のクリックで確実に切り替わる |
| 6 | SHOULD | スマホで軸を変えるとプレビューが見えない・保存まで遠い | 幅 768px 未満でプレビューを上に固定（sticky）、フッター（保存）を下に固定。案内「ドラッグで回転・ピンチ／ホイールで拡大」（OrbitControls のタッチ操作はそのまま有効） |
| 7 | SHOULD | Esc・外側クリックで編集内容が消える | 未保存の変更があると「変更を破棄しますか？」を確認（キャンセルが初期フォーカス）。「キャンセル」ボタンは明示的な破棄なので確認しない |
| 8 | COULD | ロケットと衛星の区別、使用中が分からない、選択肢が切れる | 近接モデルの選択を全幅にし、「衛星モデル」「ロケット（底面原点）」のグループに分ける。一覧に「ロケット」「近接で使用中」バッジ |
| 9 | COULD | 文言 | 原点が底面（ロケット）のときは「機首（+X）」「腹側（+Z）」、衛星は「進行方向（+X）」「地球側・センサ方向（+Z）」。2 つ目の軸で 1 つ目と同じ文字の選択肢を無効化 |
| 10 | COULD | ファイルの差し替え | 編集時に「ファイルを差し替え…」。設定は保持し、検証・外形寸法の再計測・単位の再推定（実寸指定は維持）を行い、見つからないパドル選択は外して通知 |
