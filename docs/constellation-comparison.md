# コンステレーション設計比較

解析メニューの「コンステレーション設計比較」で、編集中の構成を最大6案取り込み、同じ期間・対象地点・要求で評価する。既存の設計探索で作った候補も、シナリオへ反映して取り込める。

1. 案に名前を付けて「現在の構成を追加」。
2. 画面を閉じてシナリオの衛星数・配置・地上局を変更し、比較画面から別案を追加。
3. 開始UTC、期間、刻み、対象地点の最低仰角、要求同時可視数、要求可用率、許容最大要求未達時間を設定。
4. 指定地点（各行 `名前, 緯度, 経度`）か矩形地域を選び「全案を解析」。

比較画面を閉じても案はページ内で保持される。再読み込み前に「比較を保存」でJSONへ保存する。

## 評価の意味

- SGP4/SDP4 と既存の `computeAccessGrid` を Worker から実行する。表示専用カタログレイヤーは対象外。
- 指定地点は標高0 km、等重み。矩形は緯度経度セル中心を評価し、`(sin φ_north − sin φ_south) Δλ` の球面面積で加重する。端数セルも実面積。西端より東端の経度が小さい場合は日付変更線を横断する。
- 時系列は両端を含み、各左端の状態を次の時刻まで積算。終点は追加の時間を持たない。最後の端数区間は実時間を使う。
- 可用率は1機以上の可視時間の割合。要求同時可視達成率は指定機数以上の割合。「最大要求未達」は指定機数に足りない連続時間。
- 判定は**全評価点**で要求可用率と許容最大要求未達時間を満たすこと。地域平均で局所的な不足を隠さない。
- FOVは表示設定から初期値をコピーし、独立した比較条件として保存する。全案の対象地点に同じFOVを適用。各案の地上局は固有の仰角・オフナディア条件で別評価し、対象地点のFOVは適用しない。
- 地上局の結果は、対象地点と同一衛星経由の接続を保証しない。ISL接続、容量、RF性能、タスク割当、日照条件付きの実観測、姿勢変更時間は扱わない。
- サンプル評価であり刻みより短い接触・中断を見落とし得る。100%も連続時間・全地域の保証ではない。

## 保存と再現

JSON（形式 `constellation-comparison`、version 1）は全案の入力TOML、共通条件、対象地域、解析結果、モデルバージョンを含む。条件または入力が変わると結果は「要再解析」となる。現在のモデルは `access-interval-v1`。

読み込み時は入力の形式・範囲・件数を検証し、展開前に機数・軌道面数を制限する。TLE以外の単体衛星は再現性のためepochの明示が必要。保存は読み戻せる10 MB以下に制限する。保存結果を信頼して表示せず再解析を要求する。元の結果はJSONとスクリプト不要のHTMLレポートで参照できる。HTMLの入力文字列はエスケープする。地点別CSVにも主要な解析条件を併記する。

対象地点400、地上局200、衛星10,000、案6、期間7日、刻み1〜600秒が上限。メモリ上限を超える組み合わせはエラーにし、条件を黙って間引かない。Workerは中止でき、画面を閉じると終了する。

## 故障・地上局停止の比較

案を選択し「故障・局停止案を追加」で元の入力を保持した比較案を作成する。故障機数・seed（mulberry32 + 部分Fisher–Yates、既存の故障モデルを共用）、停止局の配列インデックスを保存する。故障は解析期間全体に適用し、TOMLで既に除外された機体がある場合は残存機から追加で除く。同じ入力配列とseedなら同じ故障機になる。

表の衛星数は「稼働/元の入力の機数」。全機故障も解析可能。地上局ネットワークの可用率は「少なくとも1局から1機以上見える」時間で、最大断も併記する。全局停止・局未定義ならネットワーク可用率0%、最大断は全期間。局停止は対象地点の独立した可視率を変えない。要求達成判定は対象地点について行う。故障機のインデックスと停止局名は結果に記録する。

## 共通イベントタイムライン

選択案の稼働衛星と対象地点を選び「タイムラインを解析」。共通条件の期間・刻みで、食（遮蔽率50%以上）、稼働地上局ごとの接触、指定地点の可視（FOV有効時はそのAND条件）を同じ時間軸へ描画する。これは1機の幾何的機会であり、コンステレーション全体の要求同時可視数の達成時間ではない。

横軸をズームし、バーまたはキーボード操作可能なイベント一覧から区間開始を選択できる。境界の精度は刻み幅に依存する。イベントCSVと入力条件付きタイムラインJSONを出力できる。条件・選択変更で古い結果を無効化し、Workerの中止・終了に対応する。

「この案・時刻を3Dに反映」は編集構成をその案の稼働衛星・稼働局へ置き換え、選択時刻で一時停止する。FOV表示にも比較条件を反映する。元のシェル定義は比較案の入力に保持し、3Dへは展開済み衛星の単体定義として反映する。ISLシェル範囲は空に戻す。比較ワークスペースはタブ切替を越えて保持する。
