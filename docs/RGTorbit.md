# レポート ― Repeat Ground Track (RGT) 軌道の条件と設計手順

`src/lib/rgt.ts` が使う回帰軌道の条件式と解法を説明する。入力した高度・傾斜角から近い反復比を提案し、UI では「傾斜角と比から高度」「高度と比から傾斜角」の 2 モードで解を求める。

この設計計算は SGP4 に渡す軌道の候補を決めるもの。現在の平均近点角補正は標準の一次 J2 式と異なる（§4.1）。SGP4 で地上軌跡が閉じることは検証していない。全体像は [計算の概要](how-it-works.md) を参照。

---

## 1. RGT の定義（何が「繰り返し」なのか）

RGT (Repeat Ground Track) とは、衛星の **ECEF（地球固定）座標での地上軌跡** が、
ある反復周期 T_rep の後に **同じパターン** に戻る軌道である。

実務では整数比で表し、

- N_S: 反復周期中の衛星公転回数
- N_D: 反復周期中の地球ノーダル日数（Earth nodal period 基準）

として、以下を基本条件とする。

```
N_S * T_S = N_D * T_N
```

ここで、

- T_S: 衛星のノーダル周期（昇交点 -> 次の昇交点）
- T_N: 地球が軌道面（ノード）に対して 1 回転する周期（Earth nodal period）

---

## 2. ECEF で地上軌跡が閉じるための角速度条件

平均要素で見ると、RGT は次の 2 つの位相が同時に整数周回する条件に等しい。

### (A) 衛星のノード基準位相

平均緯度引数（mean argument of latitude）を

```
lambda = omega + M
```

とすると、昇交点から次の昇交点までに 2*pi 増える。
したがってノーダル周期は

```
T_S = 2*pi / (domega_dt + dM_dt)
```

### (B) 地球のノード基準位相

ECEF では、グリニッジ恒星角 theta_G が omega_E で増え、
昇交点赤経 Omega は摂動で dOmega_dt で変化する。
よって「地球（経度）が軌道面に対して進む角速度」は

```
omega_E - dOmega_dt
```

となるため、Earth nodal period は

```
T_N = 2*pi / (omega_E - dOmega_dt)
```

---

## 3. もっとも使われる RGT 条件式（整数比）

RGT は以下の比で表される。

```
tau = N_S / N_D
    = T_N / T_S
    = (dM_dt + domega_dt) / (omega_E - dOmega_dt)
```

平均運動 n に対し、摂動補正を Delta_n とすると

```
dM_dt = n + Delta_n
```

となるため、実務的には

```
tau = (n + Delta_n + domega_dt) / (omega_E - dOmega_dt)
```

という形がよく用いられる。

---

## 4. J2 摂動による代表的な平均変化率

以下は J2 のみを考えた平均（セキュラ）項の標準的な一次近似式。現在の実装式との差を後述する。

```
n = sqrt(mu_E / a^3)
```

```
dOmega_dt = - (3 * R_E^2 * J2 * sqrt(mu_E)) / (2 * a^(7/2) * (1 - e^2)^2) * cos(i)

domega_dt =   (3 * R_E^2 * J2 * sqrt(mu_E)) / (4 * a^(7/2) * (1 - e^2)^2) * (4 - 5 * sin(i)^2)

Delta_n   =   (3 * R_E^2 * J2 * sqrt(mu_E)) / (4 * a^(7/2) * (1 - e^2)^(3/2)) * (2 - 3 * sin(i)^2)
```

- mu_E: 地球の重力定数
- R_E: 地球赤道半径
- J2: 第 2 次ゾーナル項
- a, e, i: 平均要素（半長軸・離心率・傾斜角）

式では a と R_E は m、mu_E は m^3/s^2、角度は rad、変化率は rad/s。API の入出力は高度 km・傾斜角 deg で、内部で変換する。

### 4.1 現在のコードが解く式

`src/lib/rgt.ts::computeJ2Rates` は Ω と ω には上記と等価な式を使うが、`delta_n` は次の式である（`perturbation.ts` の J2 `dM/dt - n` と同じ）。

```
beta = (1-e^2)^2
k2 = 1.5*J2*R_E^2
Delta_n_code = k2*n*(1-3*sin(i)^2)/(2*a^2*beta)
```

標準式の `(2-3*sin(i)^2)/(1-e^2)^(3/2)` と異なり、円軌道 e=0 でも一致しない。以降の `F(a)=0` は実際には `Delta_n_code` を代入して解く。文書だけを標準式にしても実装結果の説明にならないため、両者を明示している。SGP4 の `sgp4init` 内の `mdot` の一次 J2 項は標準形に対応する（[Vallado et al., 2006](https://celestrak.org/publications/AIAA/2006-6753/AIAA-2006-6753.pdf) と利用中の `satellite.js` 実装を参照）。

この差は Flower の半長軸、ミッション設計の RGT 高度にも伝わる。モデルを修正する場合は、平均要素の定義を合わせた独立比較・既存シナリオへの影響評価・SGP4 地上軌跡の閉鎖検証が必要。

## 5. RGT 条件を 1 本の方程式にまとめる

与えたい繰り返し比 tau = N_S / N_D を決めると、
未知は主に a（または高度）であり、次の方程式を満たす a を解けば良い。

```
F(a; e, i, tau) = tau * (omega_E - dOmega_dt(a,e,i))
                 - (n(a) + Delta_n(a,e,i) + domega_dt(a,e,i))
               = 0
```

実装では §4.1 の `Delta_n_code` を代入し、数値的に a を求める。

---

## 6. 実装の解法

高度 h は `a-R_E` と定義する。比の提案は次の手順で行う。

1. `a0 = R_E + h` から §4.1 の変化率と `tau0` を計算する。
2. 各 N_D に対し `N_S = round(tau0*N_D)` を試し、`|tau0-N_S/N_D|` が最小の比を選ぶ。
3. 同率では短い N_D を優先し、最大公約数で簡約する。

高度を解く場合は比と傾斜角を固定し、初期高度の左右を 10 km から 1.4 倍ずつ拡張して F の符号変化を探す。その区間を二分法で解く。傾斜角を解く場合は §6.4 の走査と二分法を使う。

### 6.1 整数比の探索範囲（既定値）

API と UI の既定の探索範囲:

```
N_D (repeat days) : 1 ～ 30
N_S (repeat orbits): 1 ～ 2000
```

`error = |tau0-N_S/N_D|` は比の近さを表す。地上軌跡の位置誤差ではない。

### 6.2 高度の探索範囲（既定値）

高度の既定範囲は 120〜50,000 km。範囲内で根を挟む区間が見つからなければ `null` を返す。

### 6.3 UI の 2 モード

RGT 条件は **1本の方程式** なので、次の 2 モードが実用的である。

```
1) 傾斜角 i + RGT比 (N_S/N_D) -> 高度 h を解く
2) 高度 h + RGT比 (N_S/N_D) -> 傾斜角 i を解く
```

いずれも離心率 e は固定（通常 e=0）として扱う。

**現在の UI の制限**: `RgtConstraintSection.tsx` は高度解 `a-R_E` を小数 2 桁に丸めて `apogee_altitude` に書く。この TOML フィールドの定義は `a*(1+e)-R_E`（遠地点高度）なので、e=0 では一致するが、楕円軌道では一致しない。高度固定モードでも遠地点高度を `a-R_E` として入力している。API の高度定義と UI の格納値を区別すること。

---

### 6.4 実装 API と解の精度

- `suggestRgtRatioFromAltitudeInclination`: 比を提案するだけで、軌道を解かない。`error` は `|tau0-N_S/N_D|` であり、地上軌跡の経度誤差ではない。
- `solveAltitudeFromInclinationAndRatio`: 高度は **a−R_E**（遠地点高度や測地高度ではない）。二分法は `|F| < 1e-12 rad/s` または半長軸区間 < 1e-3 m で停止する。反復上限では区間中点を返す。
- `solveInclinationFromAltitudeAndRatio`: 既定 0〜180° を 1° 刻みで走査し、最初の符号変化区間を二分法で解く。複数解を列挙せず、符号変化を伴わない接する根は拾えない。
- `solveRgtFromAltitudeInclination`: 比の提案と高度解をまとめる。離心率は `[0,0.999999]` にクリップする。

`N_D` はノーダル日数であり UTC の 86400 秒の倍数ではない。`T_rep = N_D*2*pi/(omega_E-dOmega_dt)`。計算の収束精度とモデルの物理精度は別であり、出力を SGP4 に渡したときの地上軌跡閉鎖は保証しない。

## 7. 検証範囲

解法の収束は、現在の近似条件式を満たすことを確認するもの。高次重力場・抗力を含む軌道の微修正や、SGP4 での地上軌跡閉鎖の検証は実装していない。式の差は §4.1、UI の高度定義の不一致は §6.3 に記載している。
