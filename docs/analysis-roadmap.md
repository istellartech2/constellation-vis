# Analysis Roadmap

このメモは、解析タブを「概念設計・基本設計に使える解析ワークベンチ」に育てるための全体像をまとめたものです。

## 共通方針

- 解析タブ内で対象衛星を選択できること。
- 対象が多い場合でも、1機を深く見る解析を基本形にすること。
- 入力フォーム、KPIカード、グラフ、ダウンロードを各解析で共通化すること。
- ダウンロードは `PNG`, `HTML`, `CSV`, `JSON` を標準とすること。
- 将来の複数衛星比較やシェル代表値解析へ拡張できるよう、衛星一覧生成と解析出力型を整理すること。

## 1. 太陽光影響解析

目的:

- 軌道と日照条件から、衛星の電力成立性を評価する。
- 日陰時間、SOC、必要太陽電池能力、必要バッテリ容量を早期設計で見積もる。

入力:

- 衛星選択
- 太陽電池 BOL 出力
- 劣化率、運用年数
- 日照追尾係数、電力経路効率
- ベース負荷、日照/日陰追加負荷
- ペイロード負荷と duty
- バッテリ容量、初期SOC、最低SOC、充放電効率
- 設計マージン
- 感度解析の掃引対象とレンジ

出力:

- 周回電力タイムライン
- 24時間SOC推移
- 年代表点比較
- 1変数感度解析
- KPI:
  - 日陰時間
  - 日照率
  - 発電量/消費量
  - 正味収支
  - 最小SOC
  - 推奨最小バッテリ容量
  - 推奨最小太陽電池出力

## 2. 軌道維持燃料解析

目的:

- 摂動と抗力から寿命、軌道低下、必要ΔV、必要推進剤量を見積もる。

入力:

- 衛星選択
- バリスティック係数
- ミッション年数
- 目標維持高度帯
- 推進系比推力
- ドライ質量、推進剤マージン

出力:

- 高度低下曲線
- 年次ΔV予算
- 必要推進剤量
- 高度やバリスティック係数の感度解析
